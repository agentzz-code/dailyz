## Main navigation

1. Today
2. Study

4. Calendar

## Existing systems

- Firebase Authentication
- Firestore
- Tasks
- Prayer calculations
- Calendar
- Steps/Apple Health sync
- Notifications
- Cloudflare AI
- PWA service worker
- English/Kurdish/Arabic
- Dark mode

## Important rules

DO NOT rewrite index.html.

Preserve existing functionality.

Use existing functions instead of creating duplicates.

Do not modify Firebase configuration or Firestore rules unless explicitly requested.

Do not modify Cloudflare Workers unless explicitly requested.

Make small, isolated changes.
